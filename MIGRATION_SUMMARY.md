## Database Schema

### MongoDB (Before)

```javascript
{
  _id: ObjectId,
  name: string,
  type: 'tent' | 'hotel' | 'all',
  group: string,
  amount: number
}
```

### Convex (After)

```typescript
{
  _id: Id<"gear">,
  name: string,
  type: 'tent' | 'hotel' | 'all',
  group: string,
  amount: number
}
```

**Indexes:**

- `by_type` - Index on type field
- `by_name` - Index on name field
- `search_name` - Full-text search index on name field

## API Migration

### Before (REST API)

```typescript
GET /api/gear?type=tent
GET /api/options?q=search
```

### After (Convex Queries)

```typescript
useQuery(api.gear.getGear, { type: 'tent' });
convex.query(api.gear.searchGear, { searchTerm: 'search' });
```

## Best Practices Implemented

### 1. **Efficient Indexing**

- Created indexes on frequently queried fields (`type`, `name`)
- Implemented full-text search index for autocomplete

### 2. **Type Safety**

- Full TypeScript support with Convex-generated types
- Strict schema validation at the database level

### 3. **Reactive Data**

- Convex automatically re-fetches data when it changes
- No manual cache invalidation needed

### 4. **Optimized Queries**

- Filter at database level instead of fetching all data
- Use search indexes for text search (more efficient than regex)

### 5. **Server-Side Validation**

- Schema defined with `v.` validators
- Type checking at runtime

### 6. **Simplified Architecture**

- No need for separate backend server
- No CORS configuration needed
- Built-in authentication support (ready for future enhancement)

## Performance Improvements

### Search Functionality

- **Before**: MongoDB regex search (`$regex`, `$options: "i"`)
- **After**: Convex search index (optimized full-text search)
- **Benefit**: Faster search, better relevance ranking

### Data Fetching

- **Before**: HTTP requests with manual caching
- **After**: Reactive queries with automatic caching
- **Benefit**: Real-time updates, less boilerplate

### Deployment

- **Before**: Deploy Deno server + MongoDB setup
- **After**: Single deployment to Convex
- **Benefit**: Simpler deployment, automatic scaling
